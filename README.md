# NovaFit: набор массы без перегибов

Мобильное приложение (PWA) для безопасного набора веса. Работает в браузере телефона, ставится на главный экран как обычное приложение, работает офлайн. Все данные хранятся только на телефоне.

## Что умеет

| Вкладка | Что внутри |
|---|---|
| **Сегодня** | Кольцо калорий и полоски БЖУ, прогресс к цели, план на день: завтрак, обед, перекус и ужин с граммовками, рецептом и кнопками «Съел» / «Другой вариант» |
| **Питание → Запасы** | Список продуктов дома (76 продуктов в базе, включая те, что легко найти в любой стране, + свои). Добавлять можно поиском или **сканером штрихкодов**. Когда отмечаешь «Съел», продукты списываются сами |
| **Питание → Порция** | Выбираешь продукты, приложение считает, сколько граммов каждого съесть, чтобы закрыть норму приёма пищи |
| **Питание → Рецепты** | «Что приготовить из того, что есть»: 120 рецептов в группах «можно сейчас / не хватает одного продукта / 2–3». Замены (нет гречки — киноа, нет творога — скир), фильтры по приёму пищи, времени и «без готовки», порция под твою норму, «Поставить на сегодня», недостающее — в покупки, поиск похожих рецептов в Google и YouTube |
| **Питание → Покупки** | Список покупок на 3 или 7 дней по меню, за вычетом того, что уже есть, с английскими названиями — для магазинов в других странах. Можно скопировать. Отметил купленное, и оно попадает в запасы |
| **Тренировки** | Программа под твой инвентарь (по умолчанию одна гантель): фулбоди A/B/C или сплит «верх/низ». Запись повторений и подсказки, когда и как усложнять |
| **Сон** | Журнал сна, график за 7 ночей. По времени подъёма и отбоя строится расписание еды: ужин за 3 часа до сна, перекус за 1,5 часа до тренировки |
| **Профиль** | Норма КБЖУ с расшифровкой, график веса, еженедельная автоподстройка калорий, источники |
| **Еда вне плана** | «+ Добавить еду» на главном экране: съел что-то сверх плана, и оставшиеся приёмы пересчитываются под остаток нормы. Если норма закрыта, остаются лёгкие приёмы, а не голодовка |
| **Сроки годности** | Дата «годен до» у каждого продукта (подставляется сама по типу продукта). Что портится в ближайшие 1–3 дня, планировщик ставит в меню первым. Просроченное в меню не попадает, приложение предупреждает |
| **Напоминания** | Файл для календаря телефона (работает, даже когда приложение закрыто) и уведомления о еде, тренировке, отбое, взвешивании и замерах |
| **Таймер отдыха** | Записал подход, и сам запускается отсчёт отдыха со звуком и вибрацией. Для планки и других упражнений на время есть секундомер подхода. Экран не гаснет во время тренировки |
| **Недельный отчёт** | Калории по дням, вес против плана, белок, сон, тренировки и главный совет на следующую неделю. Можно листать 4 недели назад |
| **Замеры тела** | Талия, грудь, бицепс, бедро раз в 2 недели. Приложение сравнивает рост талии с ростом веса и подсказывает, что растёт: мышцы или жир |
| **Сканер штрихкодов** | Камера телефона или ручной ввод цифр. Товар ищется в мировой открытой базе Open Food Facts (лицензия ODbL), так что работает в любой стране. Знакомые товары узнаются без интернета. Если товара нет в базе — вводишь КБЖУ с упаковки один раз |
| **Режим «Нет аппетита»** | 6 приёмов поменьше вместо 4, калорийные блюда, жидкие калории на перекус, белковый перекус перед сном, калорийные добавки без объёма и советы, как съедать норму |
| **Вода** | Рекомендация на день с поправками на жару, перелёты и тренировки (без трекера) |
| **Путешествия** | Смена часового пояса замечается автоматически: еда, сон и напоминания переходят на местное время, есть советы при джетлаге. В APK напоминания пересчитываются по местному времени даже без открытия приложения |

## Безопасные лимиты, зашитые в код

- Калории: расход по формуле Миффлина — Сан Жеора × активность, плюс **200–500 ккал** профицита. Темп **0,25–0,5 % массы в неделю** (Iraki et al., 2019; ISSN).
- Белок: **1,6–2,2 г/кг**, выше 2,2 не поднимается (Morton et al., 2018). До 18 лет 1,6 г/кг.
- Жиры: 25–30 % калорий, но **не меньше 0,8 г/кг**, не больше 35 %.
- Автоподстройка: раз в неделю ±100 ккал по фактическому весу, **в сумме не больше ±300**.
- Максимум продукта на один приём (например, не больше 4 яиц и 40 г арахисовой пасты).
- Предупреждения: возраст до 18 лет (только плавный темп и совет показать план врачу); ИМТ < 16 (сначала к врачу, профицит не больше 300 ккал); ИМТ ≥ 25; цель с ИМТ > 27.
- Никаких «гормональных» добавок. Из спортпита упомянуты только протеин и креатин 3–5 г для взрослых.

NovaFit не заменяет врача или диетолога.

## Установка на Android (APK)

Готовый файл: [`dist/NovaFit.apk`](dist/NovaFit.apk) (версия 1.2, ≈2 МБ, Android 7.0 и новее). Ставится поверх прежних версий без потери данных.

1. Открой файл на телефоне (или скачай со страницы репозитория: `dist/NovaFit.apk` → «Download raw file»).
2. Телефон спросит разрешение «Устанавливать неизвестные приложения» для браузера или файлового менеджера — разреши.
3. «Установить». Google Play Защита может предупредить, что приложение незнакомое (оно не из Play Маркета) — выбери «Всё равно установить».
4. При первом включении напоминаний разреши уведомления. Чтобы напоминания приходили минута в минуту, разреши «Будильники и напоминания» (кнопка появится в профиле).

Что даёт APK по сравнению с сайтом: напоминания приходят, даже когда приложение закрыто (и после перезагрузки или перелёта), таймер отдыха сигналит из свёрнутого приложения, экран не гаснет на тренировке, шрифты встроены — интернет нужен только для поиска новых товаров по штрихкоду. При первом сканировании Android спросит разрешение на камеру.

Сборка: `npm run android` (нужны JDK 17+, Android SDK 34 и Gradle 8.9+). Ключ подписи (`android/novafit-release.jks` и `android/keystore.properties`) в репозиторий не кладётся. Новая версия встанет поверх старой без потери данных, только если подписана тем же ключом. Без него приложение придётся удалить и поставить заново: перед этим сохрани данные через «Профиль → Данные → Скопировать данные».

## Установка как веб-приложение (iPhone и Android)

1. Включи GitHub Pages: **Settings → Pages → Source: GitHub Actions**. После пуша в `main` приложение будет по адресу `https://<логин>.github.io/NovaFit/`.
2. Открой ссылку на телефоне:
   - **iPhone (Safari):** «Поделиться» → «На экран Домой».
   - **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».

Без хостинга: `npm run build` собирает всё приложение в один файл `dist/novafit.html`, его можно открыть в браузере.

## Разработка

```bash
npm test        # проверки расчётов (КБЖУ, лимиты, планировщик, программа тренировок)
npm run e2e     # сквозной прогон интерфейса в Chromium (Playwright)
npm run e2e:scanner  # сканер: фейковая камера показывает штрихкод, ответ Open Food Facts подменён
npm start       # локальный сервер на http://localhost:8080
```

Структура: `js/data-*.js` — базы продуктов (сроки хранения, замены, английские названия), рецептов и упражнений; `js/scanner.js` — сканер штрихкодов и разбор Open Food Facts (`js/vendor/zxing.min.js` — распознавание, Apache 2.0); `js/insights.js` — недельный отчёт, замеры, напоминания и экспорт в календарь; `js/nutrition.js` — расчёт нормы и адаптация; `js/planner.js` — расписание по сну, подбор граммовок, меню, покупки; `js/workout.js` — программа под инвентарь и прогрессия; `js/app.js` — интерфейс.
