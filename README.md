# NovaFit: набор массы без перегибов

Мобильное приложение (PWA) для безопасного набора веса. Работает в браузере телефона, ставится на главный экран как обычное приложение, работает офлайн. Все данные хранятся только на телефоне.

## Где что находится

Внизу четыре раздела и кнопка «+» посередине. Настройки открываются шестерёнкой в правом верхнем углу. Подробности (блюдо, рецепт, продукт, формы) выезжают шторкой снизу, экран под ней не меняется.

| Раздел | Что внутри |
|---|---|
| **Сегодня** | Сколько калорий осталось съесть, белок и вода на день. Ниже лента дня по времени: подъём, приёмы пищи, тренировка, еда вне плана, отбой и отметка «сейчас». Галочка справа — «Съел», тап по карточке — состав с граммовками, рецепт и «Другое блюдо». Сверху одна заметка о самом важном (просрочка, перелёт, устаревшее меню) |
| **Еда → Холодильник** | Продукты дома по категориям со сроками годности. Добавить поиском или по штрихкоду. «Тарелка» считает, сколько граммов каждого продукта съесть на приём |
| **Еда → Рецепты** | «Что приготовить из того, что есть»: 120 рецептов в группах «можно сейчас / нет одного продукта / 2–3», замены, фильтры, порция под норму, «Поставить на сегодня», недостающее — в покупки |
| **Еда → Покупки** | Список на 3 или 7 дней по меню за вычетом того, что есть дома, с английскими названиями. Отметил купленное — оно в холодильнике |
| **Тренировка** | Следующая тренировка под твой инвентарь, упражнения с техникой, запись подходов прямо на экране, таймер отдыха, история |
| **Прогресс** | Вес и график к цели, недельный отчёт, сон за 7 ночей, замеры тела, норма КБЖУ с расшифровкой |
| **Кнопка «+»** | Всё, что записываешь: съел вне плана, купил продукты, штрихкод, вес, сон, замеры |
| **Шестерёнка** | Мои данные, режим сна, инвентарь и дни тренировок, режим «Нет аппетита», напоминания, перенос данных, откуда цифры |

## Что умеет

| Функция | Как работает |
|---|---|
| **Меню из того, что есть** | 76 продуктов в базе (включая те, что легко найти в любой стране) и свои. Когда отмечаешь «Съел», продукты списываются из холодильника сами |
| **Еда вне плана** | Съел что-то сверх плана — оставшиеся приёмы пересчитываются под остаток нормы. Если норма закрыта, остаются лёгкие приёмы, а не голодовка |
| **Сроки годности** | Дата «годен до» подставляется сама по типу продукта. Что портится в ближайшие 1–3 дня, планировщик ставит в меню первым. Просроченное в меню не попадает |
| **Сон → расписание еды** | Завтрак через 40 минут после подъёма, ужин за 3 часа до сна, перекус за 1,5 часа до тренировки |
| **Тренировки под инвентарь** | По умолчанию одна гантель: фулбоди A/B/C или сплит «верх/низ». Подсказки, когда и как усложнять |
| **Таймер отдыха** | Записал подход — сам запускается отсчёт со звуком и вибрацией. Для планки и упражнений на время есть секундомер подхода. Экран не гаснет во время тренировки |
| **Напоминания** | Файл для календаря телефона и уведомления о еде, тренировке, отбое, взвешивании и замерах |
| **Недельный отчёт** | Калории по дням, вес против плана, белок, сон, тренировки и главный совет на следующую неделю. Можно листать 4 недели назад |
| **Замеры тела** | Талия, грудь, бицепс, бедро раз в 2 недели. Приложение сравнивает рост талии с ростом веса и подсказывает, что растёт: мышцы или жир |
| **Сканер штрихкодов** | Камера или ручной ввод цифр. Товар ищется в мировой открытой базе Open Food Facts (лицензия ODbL), так что работает в любой стране. Знакомые товары узнаются без интернета |
| **Режим «Нет аппетита»** | 6 приёмов поменьше вместо 4, калорийные блюда, жидкие калории, белковый перекус перед сном и советы, как съедать норму |
| **Вода** | Рекомендация на день с поправками на жару, перелёты и тренировки (без трекера) |
| **Путешествия** | Смена часового пояса замечается автоматически: еда, сон и напоминания переходят на местное время, есть советы при джетлаге |

## Безопасные лимиты, зашитые в код

- Калории: расход по формуле Миффлина — Сан Жеора × активность, плюс **200–500 ккал** профицита. Темп **0,25–0,5 % массы в неделю** (Iraki et al., 2019; ISSN).
- Белок: **1,6–2,2 г/кг**, выше 2,2 не поднимается (Morton et al., 2018). До 18 лет 1,6 г/кг.
- Жиры: 25–30 % калорий, но **не меньше 0,8 г/кг**, не больше 35 %.
- Автоподстройка: раз в неделю ±100 ккал по фактическому весу, **в сумме не больше ±300**.
- Максимум продукта на один приём (например, не больше 4 яиц и 40 г арахисовой пасты).
- Предупреждения: возраст до 18 лет (только плавный темп и совет показать план врачу); ИМТ < 16 (сначала к врачу, профицит не больше 300 ккал); ИМТ ≥ 25; цель с ИМТ > 27.
- Никаких «гормональных» добавок. Из спортпита упомянуты только протеин и креатин 3–5 г для взрослых.

NovaFit не заменяет врача или диетолога.

## Установка на Android (APK)

Готовый файл: [`dist/NovaFit.apk`](dist/NovaFit.apk) (версия 2.0, ≈2 МБ, Android 7.0 и новее). Ставится поверх прежних версий без потери данных.

1. Открой файл на телефоне (или скачай со страницы репозитория: `dist/NovaFit.apk` → «Download raw file»).
2. Телефон спросит разрешение «Устанавливать неизвестные приложения» для браузера или файлового менеджера — разреши.
3. «Установить». Google Play Защита может предупредить, что приложение незнакомое (оно не из Play Маркета) — выбери «Всё равно установить».
4. При первом включении напоминаний разреши уведомления. Чтобы напоминания приходили минута в минуту, разреши «Будильники и напоминания» (кнопка появится в настройках → «Напоминания»).

Что даёт APK по сравнению с сайтом: напоминания приходят, даже когда приложение закрыто (и после перезагрузки или перелёта), таймер отдыха сигналит из свёрнутого приложения, экран не гаснет на тренировке, шрифты встроены — интернет нужен только для поиска новых товаров по штрихкоду. При первом сканировании Android спросит разрешение на камеру.

Сборка: `npm run android` (нужны JDK 17+, Android SDK 34 и Gradle 8.9+). Ключ подписи (`android/novafit-release.jks` и `android/keystore.properties`) в репозиторий не кладётся. Новая версия встанет поверх старой без потери данных, только если подписана тем же ключом. Без него приложение придётся удалить и поставить заново: перед этим сохрани данные через «Настройки → Данные → Скопировать данные».

## Установка как веб-приложение (iPhone и Android)

1. Включи GitHub Pages: **Settings → Pages → Source: GitHub Actions**. После пуша в `main` приложение будет по адресу `https://<логин>.github.io/NovaFit/`.
2. Открой ссылку на телефоне:
   - **iPhone (Safari):** «Поделиться» → «На экран Домой».
   - **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».

Без хостинга: `npm run build` собирает всё приложение в один файл `dist/novafit.html`, его можно открыть в браузере.

## Разработка

```bash
npm test        # проверки расчётов (КБЖУ, лимиты, планировщик, программа тренировок)
npm run e2e     # сквозной прогон интерфейса в Chromium (Playwright)
npm run e2e:scanner  # сканер: фейковая камера показывает штрихкод, ответ Open Food Facts подменён
npm start       # локальный сервер на http://localhost:8080
```

Структура: `js/data-*.js` — базы продуктов (сроки хранения, замены, английские названия), рецептов и упражнений; `js/scanner.js` — сканер штрихкодов и разбор Open Food Facts (`js/vendor/zxing.min.js` — распознавание, Apache 2.0); `js/insights.js` — недельный отчёт, замеры, напоминания и экспорт в календарь; `js/nutrition.js` — расчёт нормы и адаптация; `js/planner.js` — расписание по сну, подбор граммовок, меню, покупки; `js/workout.js` — программа под инвентарь и прогрессия; `js/app.js` — интерфейс.
